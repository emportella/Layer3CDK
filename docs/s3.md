# S3 Package

Provides a construct for creating a general-purpose, secure-by-default S3 bucket.

> For static website / SPA hosting (S3 + CloudFront + ACM + Route 53), use the
> [Static Site S3](./static-site-s3.md) construct instead.

## S3Bucket

`S3Bucket` creates a private S3 bucket with secure defaults, environment-aware
configuration, a storage-growth CloudWatch alarm, and IAM grant helpers.

**Secure by default:**

- All public access blocked (`BlockPublicAccess.BLOCK_ALL`)
- SSL enforced (`enforceSSL`)
- S3-managed encryption (`BucketEncryption.S3_MANAGED`)
- `ObjectOwnership.BUCKET_OWNER_ENFORCED` (ACLs disabled)

### Properties

Like `DynamoTable`, the bucket properties are split into two layers:

- `S3Config` — _Optional_ library-managed configuration (`bucketConfig`).
  - Environment-aware; user values are **deep-merged** on top of the library
    defaults via `resolveAndMergeEnvProps()`.
  - Manages the secure/operational fields:
    - `blockPublicAccess`
    - `encryption` / `encryptionKey`
    - `enforceSSL`
    - `objectOwnership`
    - `versioned`
    - `removalPolicy`
    - `autoDeleteObjects`
  - Plus the alarm threshold `alarmBucketSizeBytesThreshold` (bytes).
- `S3Props` — _Optional_ structural passthrough to the underlying CDK `Bucket`
  (`bucketProps`).
  - Use for `lifecycleRules`, `cors`, `eventBridgeEnabled`,
    `transferAcceleration`, `intelligentTieringConfigurations`, etc.
  - The security-sensitive fields above are managed by `S3Config` and are
    intentionally not settable here.

### Defaults

| Field                           | `default` (dev/stg)     | `prd`                 |
| ------------------------------- | ----------------------- | --------------------- |
| `removalPolicy`                 | `DESTROY`               | `RETAIN`              |
| `autoDeleteObjects`             | `true`                  | `false`               |
| `versioned`                     | `false`                 | `true`                |
| `alarmBucketSizeBytesThreshold` | `50 GiB`                | `500 GiB`             |
| `blockPublicAccess`             | `BLOCK_ALL`             | `BLOCK_ALL`           |
| `encryption`                    | `S3_MANAGED`            | `S3_MANAGED`          |
| `enforceSSL`                    | `true`                  | `true`                |
| `objectOwnership`               | `BUCKET_OWNER_ENFORCED` | `BUCKET_OWNER_ENFORCED` |

### Production validations

When `stackEnv === 'prd'`, the construct adds CDK validations that fail `synth`
if the bucket would:

- use `RemovalPolicy.DESTROY`,
- enable `autoDeleteObjects`, or
- have versioning disabled.

### Alarms

S3 exposes no native operational metrics, so `setCloudWatchAlarms()` creates a
single **bucket size** alarm on the daily `BucketSizeBytes` (StandardStorage)
metric as a storage-growth / cost guardrail. The threshold comes from
`alarmBucketSizeBytesThreshold`. Add more via `setCustomAlarms()`.

### Naming

```
Bucket: dev-banana-launcher-uploads
```

`<stackEnv>-<serviceName>-<bucketName>`, lowercased (bucket names must be
globally unique and lowercase).

### Example

```typescript
import { Duration } from 'aws-cdk-lib';
import { BaseEnvProps, S3Bucket, S3Config, S3Props } from '@emportella/layer3cdk';

const bucketProps: BaseEnvProps<S3Props> = {
  default: {
    lifecycleRules: [{ expiration: Duration.days(90) }],
  },
};

const bucketConfig: BaseEnvProps<S3Config> = {
  default: { alarmBucketSizeBytesThreshold: 50 * 1024 ** 3 },
  prd: {
    alarmBucketSizeBytesThreshold: 1024 ** 4, // 1 TiB
    versioned: true,
  },
};

const bucket = new S3Bucket(this, {
  config: this.config,
  bucketName: 'uploads',
  bucketProps,
  bucketConfig,
});

// Grant access to a role. Also: grantReadOnlyPolicies, grantCustomPolicies.
bucket.grantPolicies(this.serviceAccount.getRole());

// Storage-growth alarm wired to your alarm action.
bucket.setCloudWatchAlarms(this.config.alarmAction);

// Escape hatch for advanced wiring (event notifications, etc.).
bucket.getBucket().addEventNotification(/* ... */);
```
